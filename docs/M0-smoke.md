# M0 冒烟清单

装完必须**重启 DSH**（不是刷新页面）。本清单按「先证能加载、再证功能、最后证清理」分级。

逐项打勾；任一项失败就先回滚，不要继续往上加功能。

---

## 0. 安装与重启

```sh
D="/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh"
"$D" plugin --profile desktop add /Users/gww/Desktop/开发项目/共创项目/dsh-immersion-glow
```

确认两件事：

- [ ] `~/.dsh/profiles/desktop/package.json` 里 `dependencies` 出现
      `"dsh-immersion-glow": "link:…/dsh-immersion-glow"`
- [ ] 同文件 `dsh.profile.bundles` 数组末尾出现 `"dsh-immersion-glow"`

然后**完全退出 DSH 并重新打开**。

> 回滚：`"$D" plugin --profile desktop remove dsh-immersion-glow`，再重启。

---

## 1. 最关键的一项：前端能正常加载

- [ ] 打开任意会话，界面正常，**没有**出现
      「Failed to load plugins」/ 「N entries did not activate」

> 这一项不过，说明 `inject` 里有拿不到的服务导致 fiber pending。整个前端都会被拖住，
> 必须先看控制台里 pending 的插件名与缺失服务。

---

## 2. 三处挂载点同时生效

- [ ] `设置 → 通用` 里出现「沉浸觉察」一行（标题 + 描述 + 启用开关）
- [ ] 输入框工具行左侧（`conversation.input.left`）**没有**多余内容（默认渲染 null，
      这是**正确**表现，不是失败）
- [ ] `设置 → 插件` 里出现「沉浸觉察」卡片，标题是中文而不是包名

## 3. 提醒卡能出现

快速到达触发点：把设置里的阈值改成 `1`（1 分钟），然后持续操作 1 分钟以上。

- [ ] 右上角出现提醒卡，有 60 秒倒计时在走字
- [ ] 卡片不挡住会话内容（可以正常点输入框、发消息）
- [ ] 点 `×` → 卡片消失
- [ ] 再等 1 分钟（末档步长）→ 提醒卡再次出现

## 4. 未读徽标、记录卡与画廊

- [ ] 触发一次后**什么都不点**，等 60 秒 → 卡片缩成一条未读徽标，一直留着
- [ ] 点徽标 → 徽标消失，记录卡浮出，显示「沉浸时长 / 对话轮次 / 工具调用」三格
- [ ] 轮次与工具调用**不是** `0`（在有多轮对话的会话里）
- [ ] 在长会话里查看是否出现「仅统计当前窗口内的数据」说明 ——
      如果出现，说明 `hasMore` 派生正确
- [ ] 点「收藏这张记录」→ 提醒卡提示「已收藏」，**到点自动消失、不留未读**；
      同时设置行「收藏」按钮变为「查看收藏（N）」
- [ ] 点「查看收藏」→ 画廊里有刚才那条
- [ ] 画廊里点 `×` → 该条消失
- [ ] 再收藏两条，点「清空全部」→ 第一次变成「再点一次确认清空」，第二次才真清
- [ ] 切到**没有会话**的首页/欢迎页 → 记录卡显示「无打开会话，以下为上一次会话的统计」

## 5. 持久化与降级

- [ ] 改几个设置（阈值、空闲分钟）→ **刷新页面** → 设置还在
- [ ] 新开一个标签页 → 设置与画廊数据都在
- [ ] 手动破坏持久化：控制台执行
      ```js
      localStorage.setItem('immersion-glow.v1', '{broken')
      ```
      刷新 → 插件仍正常启动（数据回到默认），**不阻塞前端**

## 6. 埋点与 i18n

- [ ] 设置行的埋点文案随触发次数增长：「已提醒 N 次 · 你打开了 M 次」
- [ ] 点「复制统计」→ 提醒卡提示「统计信息已复制到剪贴板」，粘贴出来是合法 JSON，
      且含 `"schema": "immersion-glow/stats"` 与 `"version": 1`
- [ ] 切 `设置 → 通用 → Language` 到 English → 本插件所有文案跟着变，
      **没有**裸 key（如 `settings.title`）

## 7. 视觉与性能

- [ ] 提醒卡进出期间，DevTools Performance 录制里**没有** Layout / Paint 条目
      （只有 Composite）
- [ ] 系统开启「减少动态效果」后，提醒卡改为淡入，不缩放
- [ ] 与已装的 `dsh-pet` 浮球**不打架**（右上角 vs 右下角）
- [ ] 暗色主题下提醒卡可见但不刺眼

## 8. 清理（卸载级联）

- [ ] 卸载插件（见第 0 节回滚命令）→ 重启 → 设置行、提醒卡、画廊全部消失
- [ ] 控制台无残留定时器报错；页面无 `[immersion-glow]` 相关告警

---

## 已知不影响通过的差异

| 现象 | 说明 |
|---|---|
| 输入框左侧长期空白 | 设计如此。常驻计时默认关闭，需在设置里打开 |
| 白天做的记录没有「晨间/深夜」标签 | 设计如此，白天不打时间标签（多数会话在白天，标了没信息量） |
| 短会话不产生收藏候选 | 时段需 ≥ 5 分钟才自动入库，避免碎片垃圾 |
| 空闲 3 分钟后计时停住 | 设计如此：沉浸时长 = 活跃时长 |
| 隐藏标签页 10 分钟以上再回来，时长归零 | 设计如此：视为新时段，不做反向补算 |
